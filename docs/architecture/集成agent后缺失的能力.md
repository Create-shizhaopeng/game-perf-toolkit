## 概述

本文档记录 `agent_chat` 模块集成后，与原始需求相比尚未覆盖的功能领域。随着开发推进逐步补全并在此更新。

## 当前已实现的 Agent 能力

| 能力 | 说明 |
|------|------|
| LLM 对话 | 支持 GLM / Claude 双引擎流式对话 |
| 工具调用 | 自动发现并执行各模块 `register_agent_tools` 注册的工具 |
| SOP 管理 | 内置 SOP 加载 + 用户自定义 SOP 导入/导出/删除 |
| 对话记忆 | SQLite 持久化多会话对话历史 |
| 工作流追踪 | 记录工具调用序列，检测沉淀条件 |
| 报告索引 | 扫描历史报告目录提取摘要，注入 system prompt |
| GUI + CLI | Agent Tab 完整聊天界面 + `agent ask` / `agent sop` CLI 命令 |

## 待补全的能力

| 能力 | 优先级 | 说明 |
|------|--------|------|
| Token 用量展示 | P2 | 每次回复后显示 input/output token 和费用预估 |
| Provider 智能切换 | P2 | 根据场景复杂度和可用 Key 自动选择最佳 Provider |
| 工作流自动沉淀 | P2 | 满足条件时自动生成 SOP 并提示用户保存 |
| 综合卡顿分析 SOP 联动 | P3 | jank_comprehensive SOP 与多模块数据联合分析 |
| 文件拖拽上传 | P3 | 输入区支持拖拽 trace/PerfDog 文件并自动识别类型 |
| 工具执行中的进度反馈 | P3 | Agent 执行长时工具时在 GUI 显示进度条 |
