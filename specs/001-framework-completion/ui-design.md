## 1. 设计概览

工具采用无边框窗口设计，自定义标题栏集成设备状态和主题切换。整体布局为「标题栏 + 左导航 + 右内容区」三栏结构。支持暗色/亮色两套主题，运行时即时切换。

---

## 2. 主窗口整体布局

### 2.1 布局结构

```
┌──────────────────────────────────────────────────────────────────────┐
│  TitleBar (h=32px, 固定高度)                                        │
│  [◇LVGT] ──── [●设备选择器▼] ──── [☀/🌙] [─] [□] [✕]              │
├────────┬─────────────────────────────────────────────────────────────┤
│        │                                                             │
│  Nav   │                   Content Area                              │
│ Panel  │                (QStackedWidget)                             │
│ 120~   │                                                             │
│ 300px  │  ┌───────────────────────────────────────────────────────┐  │
│        │  │  当前选中的 Tab 内容                                  │  │
│ [🏠首页]│  │  - 首页: 状态总览 + 模块列表                          │  │
│ [🔧模块]│  │  - 模块页: 各模块独立 GUI                             │  │
│ [📊模块]│  │                                                       │  │
│        │  └───────────────────────────────────────────────────────┘  │
│   ↔    │                                                             │
├────────┴─────────────────────────────────────────────────────────────┤
│  StatusBar (h=24px)  [就绪]  ────────────────────────  [v1.0.0]     │
└──────────────────────────────────────────────────────────────────────┘
```

### 2.2 区域说明

| 区域 | 组件 | 尺寸 | 说明 |
|------|------|------|------|
| TitleBar | `TitleBar` | 全宽 × 32px | 自定义标题栏，拖拽可移动窗口 |
| NavPanel | `NavPanel` | 120-300px × 自适应 | 左侧导航，QSplitter 可拖拽调整宽度 |
| ContentArea | `QStackedWidget` | 自适应 × 自适应 | 右侧内容区，模块页面堆栈 |
| StatusBar | `QWidget` | 全宽 × 24px | 底部状态栏，显示连接状态和版本号 |

- 窗口最小尺寸：1024 × 640
- 默认尺寸：1200 × 800
- 窗口标志：`FramelessWindowHint`（无系统标题栏）
- 边缘缩放：4px 拖拽边距，Python 层面实现
- 导航栏与内容区通过 `QSplitter` 分隔，支持拖拽调整

### 2.3 窗口缩放行为

| 交互 | 行为 |
|------|------|
| 拖拽窗口边缘 | 各维度独立缩放，最小 1024×640 |
| 点击最大化按钮 | 全屏贴合，边距归零，按钮图标切换为双矩形叠加 |
| 最大化状态点击最大化 | 恢复之前尺寸，边距恢复 4px |
| 双击标题栏 | 等同最大化/恢复，以鼠标位置为中心定位 |
| 最大化状态拖拽标题栏 | 自动恢复并跟随鼠标拖拽 |
| 鼠标离开窗口边缘 | 光标自动恢复箭头样式 |

## 3. 标题栏 (TitleBar)

### 3.1 布局

```
┌──────────────────────────────────────────────────────────────────┐
│ [◇LVGT]  ──stretch── [●设备选择器▼] ──stretch── [☀/🌙] [─] [□] [✕]│
│  Logo                 DeviceComboBox              主题  最小 最大 关闭│
└──────────────────────────────────────────────────────────────────┘
```

- 高度：32px（固定）
- 内边距：左 8px，右 0px
- 拖拽区域：整个标题栏除按钮和下拉框外
- 双击空白区域：最大化/恢复

### 3.2 自定义组件

所有标题栏组件均为矢量绘制（`paintEvent`），无图片依赖，主题自适应：

| 组件 | 类名 | 尺寸 | 说明 |
|------|------|------|------|
| Logo | `LogoWidget` | 110 × 30 | 菱形图标 + "LVGT" 文字，暗色紫/亮色深紫 |
| 主题切换 | `ThemeButton` | 36 × 28 | 暗色显示月亮弧线，亮色显示太阳光线 |
| 设备选择器 | `DeviceComboBox` | 200 × 22 | 内嵌状态指示灯，文字居中，点击任意位置弹出下拉 |

**设备状态指示灯**（集成在 DeviceComboBox 内部）：

| 状态 | 颜色 | 提示文字 |
|------|------|----------|
| 无设备连接 | `#e74c3c` (红) | "未连接设备" |
| 1 台设备连接 | `#2ecc71` (绿) | "已连接: {设备名}" |
| 多台设备连接 | `#3498db` (蓝) | "{N} 台设备已连接" |

### 3.3 设备选择器

- 类型：自定义 `DeviceComboBox`（继承 `QComboBox`）
- 固定宽度：200px，高度 22px
- 文字居中对齐（`QLineEdit` readonly + AlignCenter）
- 左侧 10px 处绘制 3.5px 半径状态圆点
- 占位文字（无设备时）："未连接设备"
- 点击 lineEdit 区域通过 `eventFilter` 触发下拉

### 3.4 窗口控制按钮

统一使用 `WinCtrlButton`（VS Code 风格，46×30），矢量绘制图标：

| 按钮 | 图标 | 尺寸 | 功能 |
|------|------|------|------|
| 最小化 | 水平线段 | 46 × 30 | 最小化窗口 |
| 最大化 | 矩形/双矩形叠加 | 46 × 30 | 最大化/还原，图标随状态切换 |
| 关闭 | X 交叉线 | 46 × 30 | 关闭应用，悬停红色背景 |

## 4. 导航面板 (NavPanel)

### 4.1 布局

```
┌──────────┐
│ 🏠 首页   │  ← 默认选中
│ 🔧 性能配置│  ← 模块按钮（动态生成）
│ 📊 设备伪装│
│          │
│  (stretch)│
│          │
└──────────┘
```

- 默认宽度：180px，可通过 QSplitter 拖拽调整（120-300px）
- 内边距：4px 水平，8px 垂直
- 按钮间距：2px
- 按钮最小高度：36px
- 无标题头部文字（纯按钮列表）

### 4.2 导航按钮交互

| 状态 | 样式 |
|------|------|
| 默认 | 透明背景，普通文字颜色 |
| 悬停 | 浅色背景高亮 |
| 选中 (checked) | 强调色背景 + 白色文字 |

- 按钮类型：`QPushButton`（checkable），互斥选中
- 首页按钮为默认选中项
- 模块按钮根据 `register_gui_tab` 钩子返回结果动态生成

## 5. 首页 (HomeTab)

### 5.1 布局

```
┌─────────────────────────────────────────────────────────────┐
│  欢迎使用 LV Game Toolkit                                    │  ← 主标题 (20px, bold, 紫色)
│  游戏开发测试工具集 — 集成设备管理、性能分析、日志分析等能力    │  ← 副标题 (13px, 灰色)
│  ───────────────────────────────────────────────────────── │  ← 分隔线
│                                                             │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐      │
│  │ 设备状态   │ │ 已加载模块│ │ 数据库    │ │ 当前主题  │      │  ← 状态卡片 (4列)
│  │ 未连接     │ │ 2        │ │ 就绪     │ │ 暗色     │      │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘      │
│                                                             │
│  已加载模块                                                   │  ← 模块列表标题
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 设备伪装  v1.0.0  设备 model 名称修改工具              │   │  ← 模块卡片
│  │ 游戏性能  v1.0.0  游戏性能配置管理工具                  │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│                                            v1.0.0          │  ← 版本号 (右下角)
└─────────────────────────────────────────────────────────────┘
```

### 5.2 状态卡片

4 张卡片横排，使用 `QGridLayout`，间距 12px：

| 卡片 | 标题颜色 | 强调色 | 默认值 |
|------|---------|--------|--------|
| 设备状态 | `#a6adc8` | `#f38ba8` (粉红) | "未连接" |
| 已加载模块 | `#a6adc8` | `#a6e3a1` (绿色) | "0" |
| 数据库 | `#a6adc8` | `#89b4fa` (蓝色) | "就绪" |
| 当前主题 | `#a6adc8` | `#fab387` (橙色) | "暗色" |

卡片样式：
- 固定宽度 180px，高度自适应
- 边框：1px solid（主题自适应：暗 `#313244`，亮 `#ccd0da`），圆角 8px
- 左侧强调条：3px 宽度
- 标题字号：11px，灰色粗体（主题自适应：暗 `#a6adc8`，亮 `#616161`）
- 数值字号：22px，粗体，使用对应强调色
- 4 张卡片始终左对齐，不随窗口拉伸（`QHBoxLayout` + stretch）
- 主题切换时通过 `set_theme()` 更新所有内联样式

### 5.3 模块列表

- 每个模块显示为一个卡片行：名称（粗体 13px）+ 版本号 + 描述
- 模块卡片最大宽度 756px（= 4×180 + 3×12 间距），与状态卡片总宽度对齐
- 无模块时显示斜体文字："暂无已加载模块"
- 卡片边框：主题自适应，悬停时边框色加深
- 所有颜色通过主题颜色字典 `_THEME_COLORS` 管理

## 8. 设备连接状态交互

### 8.1 设备连接变化 (对应 spec FR-003, FR-015)

| 场景 | 标题栏行为 | 首页行为 | 模块页面行为 |
|------|-----------|---------|-------------|
| 无设备 → 连接 | 指示灯变绿，下拉框显示设备名 | 设备卡片更新设备名 | 设备操作按钮启用 |
| 连接 → 断开 | 指示灯变红，下拉框显示"未连接设备" | 设备卡片更新"未连接" | 设备操作按钮禁用，点击提示"设备已断开" |
| 多设备连接 | 指示灯变蓝，下拉框列出所有设备 | 设备卡片显示 "{N} 台" | 操作针对当前选中设备 |
| 设备断开（使用中） | 同上 | 同上 | **工作区数据保留不丢失**，仅禁用设备操作按钮 |

### 8.2 设备监控

- `DeviceMonitor` 在后台线程定期扫描设备（通过 `AdbManager.list_devices()`）
- 设备变化时通过 `devices_changed` 信号通知标题栏和首页
- 首页的 `update_status()` 同步更新所有状态卡片
