## 前置条件

- 本地已安装依赖并可运行 GUI
- `perfetto_capture` 与 `agent_chat` 模块均已加载
- 左侧历史面板存在至少 1 条历史数据

## 启动与基础检查

1. 在项目根目录启动 GUI：
   - `python -m toolkit.app --debug`
2. 确认右侧 Agent 面板可通过标题栏按钮打开/关闭。
3. 确认左侧历史面板可显示“抓取历史/分析历史”条目。

## 核心流程验证

1. 在左侧任一历史条目上右键，选择“发送到 Agent 对话”。
2. 预期：
   - 右侧 Agent 面板自动打开；
   - 输入框上方出现上下文区域；
   - 显示 `file_name` 和 `file_path`。
3. 再选择另一个不同文件发送。
4. 预期：
   - 上下文区域出现两条上下文项；
   - 若重复发送同一路径，不新增重复项。
5. 发送消息“分析这些文件”。
6. 预期：
   - 请求发出前用户消息尾部拼接活跃文件路径；
   - 多文件路径均可见且无重复。

## 会话隔离验证

1. 在会话 A 注入多个上下文。
2. 新建会话 B。
3. 预期：
   - 会话 B 上下文区域为空。
4. 切回会话 A。
5. 预期：
   - 会话 A 恢复之前的上下文列表。

## 边界场景验证

1. 点击某上下文项 `×`，验证仅移除该项。
2. 选中某上下文项后按 Backspace 或 Delete，验证该项被删除。
3. 对不存在路径的历史记录发送上下文，验证：
   - 仍可展示；
   - 显示“文件不存在”标记（若实现该标记）。
