## 3. 主窗口布局

- [主窗口-暗色主题](assets/ui-dark-theme.svg)（在浏览器中打开查看）
- [主窗口-亮色主题](assets/ui-light-theme.svg)（在浏览器中打开查看）

### 3.1 布局结构

窗口固定宽度 720px，最小窗口 640x520，分为 4 个功能区域。
使用 `preserveAspectRatio="xMidYMid meet"` 保证缩放时排版不变形。

```
┌──────────────────────────────────────────────┐
│  标题栏: ModifyModelNameTool          [⚙]    │
├──────────────────────────────────────────────┤
│  ① 当前设备信息                    [状态徽章]│
│     brand: [值]  manufacturer: [值]  model:  │
│     ● 设备已连接 · USB                       │
├──────────────────────────────────────────────┤
│  ② 伪装设备信息 [☆]                         │
│     brand: [▼]  manufacturer: [▼]  model:[▼] │
├──────────────────────────────────────────────┤
│  ③ 执行日志                                  │
│  ┌────────────────────────────────────────┐  │
│  │ ✓ adb root 成功                        │  │
│  │ ✓ adb remount 成功                     │  │
│  │ ⟳ 正在重启设备请稍后......              │  │
│  │                                        │  │
│  │ ──────────────────────────────────────  │  │
│  │ ██████████████████░░░░░░ 70%           │  │
│  └────────────────────────────────────────┘  │
├──────────────────────────────────────────────┤
│  ④   [▶ Start]    [✕ Clear]    [↺ Reset]    │
└──────────────────────────────────────────────┘
```

### 3.2 区域详解

#### ① 当前设备信息行（只读）

- 高度 90px，卡片式容器
- 标题「当前设备信息」蓝色加粗
- 三个属性以 label + 只读框（h=26px）形式横排
- 标签与框内文字使用 `dominant-baseline="central"` 保证垂直居中对齐
- 右上角状态徽章：圆角胶囊形，「● 未伪装」绿色 / 「● 已伪装」黄色
- 底部设备连接状态：绿色圆点 + 文字

#### ② 伪装设备信息行（可编辑）

- 高度 80px，卡片式容器
- 标题「伪装设备信息」橙色加粗
- [☆] 快捷选取按钮紧跟标题右侧同一行，尺寸 20x20，与标题文字等高
- 三个 ComboBox 输入框（h=28px），带下拉箭头
- 下拉列表从数据库加载所有已保存的历史值（去重排序），保存/导入后实时刷新
- 输入时通过 QCompleter 实时过滤匹配（大小写不敏感）
- 标签与框内文字使用 `dominant-baseline="central"` 保证垂直居中对齐
- 获得焦点时边框变为主题蓝

#### ③ 执行日志区

- 高度 240px，终端风格深色区域
- 标题「执行日志」蓝色加粗
- 日志逐行追加，带颜色状态标记：
  - `✓` 绿色：成功步骤
  - `⟳` 黄色：进行中步骤
  - `✗` 红色：失败/错误
- 底部固定区域（分隔线 + 进度条 + 百分比文字），等距 8px 排列于区域底部

#### ④ 操作按钮行

- 高度 70px，卡片式容器
- 三个按钮等距水平排列，尺寸统一 140x36
- Start（蓝色渐变）：主操作，带 ▶ 图标；点击前校验输入非空及与当前设备信息不一致
- Clear（中性灰）：次要操作，带 ✕ 图标
- Reset（红色渐变）：危险操作，带 ↺ 图标
- 设备未连接时三个按钮置灰不可点击

## 4. 设置菜单（齿轮按钮）

### 4.1 触发方式

- 标题栏右侧齿轮图标按钮（取代原 Import 按钮）
- 按钮样式：圆角矩形，齿轮图标居中
- 暗色主题：背景 `#3c3c3c`，图标 `#cccccc`
- 亮色主题：背景 `#e8e8e8`，图标 `#555555`

### 4.2 菜单内容

点击齿轮按钮后弹出 QMenu 下拉菜单，包含两个选项：

| 菜单项 | 图标 | 说明 |
|--------|------|------|
| Import Device Data | 文件夹图标 | 打开文件选择对话框，导入 JSON 设备档案 |
| Theme: Dark / Light | 太阳/月亮图标 | 切换主题，当前选中项前显示勾选标记 |

### 4.3 交互

- 菜单锚定在齿轮按钮正下方弹出
- 选择 "Import Device Data" 后打开系统文件选择对话框（过滤 *.json）
- 选择 "Theme" 后立即切换主题样式，无需重启
- 菜单样式跟随当前主题

## 6. 保存/编辑对话框

- [保存对话框](assets/ui-save-dialog-dark.svg)（在浏览器中打开查看）

### 6.1 布局

- 模态对话框，380x340px，最小 400x320
- 居中显示，背景半透明蒙层
- 标题栏「保存设备信息」/「编辑设备信息」，文字垂直居中
- 右上角关闭按钮 x

### 6.2 表单字段

- 标签居左（text-anchor="end"），输入框居右，水平对齐
- brand / manufacturer / model 输入框（单行，h=28px）
- 标签与输入框内文字使用 `dominant-baseline="central"` 垂直居中
- 备注输入框（多行，h=68px）
  - 标签与首行文字基线对齐
  - placeholder 灰色斜体：「请描述此设备信息对应哪些高帧游戏」

### 6.3 按钮

- Save（蓝色渐变，主操作）+ Cancel（灰色，取消操作）
- 尺寸 140x36，与主窗口按钮保持一致
- 居中对齐排列，间距 16px

## 10. 实现注意事项

### 10.1 弹窗主题继承

`DevicePopup` 使用 `QWidget` + `Popup` 标志实现，不会自动从 `QApplication` 继承 `QMainWindow/QDialog` 的背景样式。实现时需要：

- 设置 `objectName("devicePopup")` 和 `WA_StyledBackground` 属性
- 在 QSS 中为 `#devicePopup` 及其子控件（QListWidget、QLabel）显式声明背景色和文字颜色
- 暗色/亮色两套主题均需覆盖

### 10.2 QMessageBox 主题覆盖

系统默认 `QMessageBox` 在暗色主题下文字不可读，需在 QSS 中为 `QMessageBox`、`QMessageBox QLabel`、`QMessageBox QPushButton` 显式声明样式。

### 10.3 Popup 内弹窗的父窗口

从 `DevicePopup`（Popup 类型窗口）中打开 `SaveDialog` 或 `QMessageBox` 时，必须先关闭 Popup 再以 `MainWindow` 为 parent 弹出对话框。否则 Popup 会因失去焦点自动关闭，导致模态对话框的 parent 被销毁引发异常。
