## 功能概述

依次运行主项目及各模块的 pytest 测试套件，将每组测试作为独立会话执行，
避免跨目录同名测试文件导致的 pytest 模块名冲突。

## 代码规则

- **合并 / 发版前** 应保证相关测试通过；全量回归推荐运行本脚本。
- 测试本身不替代静态检查：仍须遵守 **[架构文档 §5.0 代码规则（总纲）](../../doc/architecture/architecture-overview.md#50-代码规则总纲)**（如对改动路径执行 `ruff check`）。
- 新增带独立 `tests/` 的模块时，在脚本内 **`TEST_GROUPS`** 中登记该目录（见[参数说明](#参数说明)）。

## 参数说明

无命令行参数。测试组在脚本内 `TEST_GROUPS` 列表中定义。
新增模块后，在列表中追加 `(显示名, 测试目录路径)` 即可。

## 使用示例

```powershell
.venv\Scripts\python.exe scripts\run_all_tests.py
```

## 返回值与错误

- 退出码 `0`：全部测试组通过
- 退出码 `1`：至少一个测试组失败
- 如果某个测试目录不存在，会打印警告并跳过
