## 模块简介

解析、编辑和推送游戏性能配置文件（gameperfconfig.xml）到 Android 设备。

- **前缀**：`gp_`
- **类别**：perf
- **Agent 工具**：已注册
- **详细开发规则**：见 `../AGENTS.md`

## 关键约束速查

- XML 解析统一使用 `lxml.etree`
- 推送前必须先验证 XML 合法性
- 推送前必须先备份设备上的原始配置
- 备份和推送记录通过 `context["db_manager"]` 持久化
