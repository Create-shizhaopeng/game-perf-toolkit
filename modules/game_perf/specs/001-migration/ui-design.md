## 设计约束

1. 模块 Tab 嵌入 MainWindow 右侧内容区（QStackedWidget），与其他模块平级
2. 风格与主框架一致（QSS 深色/浅色主题，字体 Segoe UI / Microsoft YaHei UI）
3. 不可修改主框架代码（主模块与子模块隔离）
4. 需容纳：配置文件选择、游戏/模式过滤、频率配置表、频率列表、策略面板（整体+模式）、执行日志、操作按钮

## 方案 A: 上下分栏（已选定）

**理由**：旧代码的右侧策略面板和频率列表占据大量横向空间，在导航+内容区的框架下横向空间有限。上下分栏可以利用纵向空间，避免水平拥挤。

```
┌─────────────────────────────────────────────────────────────────┐
│ 📂 配置文件: [____________________gameperfconfig.xml____] [浏览] │
│     拖拽 gameperfconfig*.xml 到此区域                            │
├────────────────────┬─────────────────┬──────────────────────────┤
│ 游戏: [▼ 和平精英] │ 模式: [▼ Normal] │ 备注: [___________] [另存为] │
├─────────────────────────────────────────────────────────────────┤
│                     频率配置表（可编辑）                          │
│ ┌──────┬──────┬────────┬────────┬──────┬────────┬────────┬─────┐│
│ │温度  │触发℃ │Gold下限│Gold上限│Gold  │Prime   │Prime   │...  ││
│ │等级  │      │(Hz)    │(Hz)    │索引  │下限    │上限    │     ││
│ ├──────┼──────┼────────┼────────┼──────┼────────┼────────┼─────┤│
│ │ 0    │ 36   │ 710400 │1804800 │ 2_8  │ 806400 │2016000 │...  ││
│ │ 1    │ 39   │ 710400 │1497600 │ 2_6  │ ...    │ ...    │     ││
│ └──────┴──────┴────────┴────────┴──────┴────────┴────────┴─────┘│
├──────────────────────────┬──────────────────────────────────────┤
│ 频率参考 (折叠/展开)     │ 策略面板 (折叠/展开)                  │
│ ┌────────┬───────┬──────┐│ ┌─────────────────────────────────┐ │
│ │Gold    │Prime  │GPU   ││ │ [整体策略] [性能模式策略]  切换  │ │
│ │0: 300  │0: 300 │0: 315││ │ ┌──────────┬────────────────┐  │ │
│ │1: 403  │1: 403 │1: 450││ │ │Key       │Value (可编辑)  │  │ │
│ │2: 518  │2: 499 │2: 580││ │ │ThermalSC │4000            │  │ │
│ │3: 614  │3: 576 │...   ││ │ │BindCore  │[+ 添加] [× 删] │  │ │
│ │...     │...    │      ││ │ │PerfHint  │[id] [time]     │  │ │
│ └────────┴───────┴──────┘│ │ │          │[opcode data]   │  │ │
│                          │ └─────────────────────────────────┘ │
├──────────────────────────┴──────────────────────────────────────┤
│ 执行日志                                                        │
│ [17:28:37] ✓ XML 格式检查通过                                    │
│ [17:28:38] [2/10] 读取设备 version... 设备 version = 5          │
│ ───────────────────────────── 35%                               │
├─────────────────────────────────────────────────────────────────┤
│    [▶ Start]          [✕ Clear]          [↺ Reset]              │
└─────────────────────────────────────────────────────────────────┘
```

**布局要点**：

| 区域 | 实现 | 说明 |
|------|------|------|
| 配置文件 | QFrame + QLineEdit + QPushButton | 支持拖拽，acceptDrops |
| 游戏/模式/备注 | QHBoxLayout + QComboBox + QLineEdit | 一行排列 |
| 频率配置表 | QTableWidget（11 列） | 触发温度和索引列可编辑 |
| 频率参考 | 3 × QTextEdit（只读） | 用 QSplitter 与策略面板并排 |
| 策略面板 | QTabWidget（整体/模式两个子 Tab） | 内部 QScrollArea + QGridLayout |
| 执行日志 | QTextEdit（只读）+ QProgressBar | 底部固定 |
| 操作按钮 | QHBoxLayout（3 个 QPushButton） | 底部固定 |

**优势**：
- 频率表占据全宽，数据可读性好
- 频率参考和策略面板并排但可折叠，节省空间
- 日志和按钮固定在底部，操作一致性好

## 方案 B: 左右分栏（未选用）

与旧代码布局一致：左侧放文件选择、过滤、频率表、日志、按钮；右侧放频率列表和策略面板。

```
┌─────────────────────────────────┬───────────────────────────────┐
│ 📂 配置文件: [________] [浏览]  │ Gold      Prime     GPU      │
│ 游戏: [▼] 模式: [▼]            │ 0: 300    0: 300    0: 315   │
│ 备注: [___________] [另存为]    │ 1: 403    1: 403    1: 450   │
│                                 │ ...       ...       ...      │
│ ┌────────────────────────────┐  │                               │
│ │ 频率配置表                  │  ├───────────────────────────────┤
│ │ 温度 │ 触发℃ │ Gold... │    │  │ 整体策略                     │
│ │ 0    │ 36    │ ...     │    │  │ Key          │ Value         │
│ │ 1    │ 39    │ ...     │    │  │ ...          │ ...           │
│ └────────────────────────────┘  │                               │
│                                 ├───────────────────────────────┤
│ 执行日志                        │ 性能模式策略                   │
│ ✓ push 成功                     │ Key          │ Value         │
│ ──────────── 100%               │ PerfHint     │ [id] [time]   │
│                                 │ BindCore     │ [+] [×]       │
│ [▶ Start] [✕ Clear] [↺ Reset]   │                               │
└─────────────────────────────────┴───────────────────────────────┘
```

**优势**：
- 与旧代码一致，用户无需适应新布局
- 左右分栏可通过 QSplitter 调整比例

**劣势**：
- 右侧内容区本身空间有限，再左右分会很拥挤
- 频率表 11 列在左半部分显示困难

## 通用组件

### 策略面板内部结构

策略面板使用 `QTabWidget` 包含「整体策略」和「性能模式策略」两个子页面。每个子页面内部：

```
┌──────────────────────────────────────┐
│ [节点标签名]（居中）                  │
│ ──────────────────────────────────── │
│ Key              │ Value (可编辑)    │
│ name             │ [__RenderThread_] │
│ freq             │ [__60__________]  │
│                                      │
│ [PerfHint]（特殊布局）                │
│ ──────────────────────────────────── │
│ [id: 0x12345678] [time: 100]         │
│ 数据: [__1234 5678 9abc def0__]      │
│                                      │
│ [BindCore]（特殊布局）                │
│ [添加绑核项] [删除整块BindCore]       │
│ ──────────────────────────────────── │
│ × │ tid name       │ tid value      │
│ × │ RenderThread   │ c0             │
│ × │ GameThread     │ 80             │
└──────────────────────────────────────┘
```

### XML 错误高亮样式

```
日志区域：
  [17:28:37] ✗ XML 格式错误（第 15 行）: mismatched tag
     13| <GamePolicy name="xxx">     ← 普通灰色
   → 14| <BindCore>                  ← 红色加粗 + 暗红背景
     15| </GamePolicy>               ← 普通灰色
```

### 主题适配

- 所有 QSS 样式继承主框架的 `sectionCard`、`sectionTitleBlue`、`fieldLabel` 等 class
- 使用 `set_theme()` 方法适配深色/浅色主题
- 按钮和进度条样式与 device_disguise 模块统一
