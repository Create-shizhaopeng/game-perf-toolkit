## 设计概览

历史记录功能需要在不破坏现有抓取流程的前提下，提供便捷的历史会话浏览和管理入口。

**核心需求**：

1. 入口明显但不影响主流程操作
2. 支持浏览大量历史记录（滚动 + 搜索）
3. 每个会话可展开查看 trace 列表
4. 支持快捷操作（打开、分析、删除）
5. 显示磁盘占用统计

## 选定方案：覆盖式右侧滑出面板（Overlay）

### 设计原则

- 面板**浮在主界面上方**，主界面**保持原有宽度不变**
- 通过**半透明遮罩**与主界面区隔
- 点击遮罩或关闭按钮可收起面板
- 面板固定宽度 320px

### 关键交互

1. **打开方式**：点击底部按钮行的「📂 历史」按钮
2. **面板动画**：从右侧滑入，持续 200-300ms
3. **遮罩**：主界面覆盖半透明遮罩（rgba(0,0,0,0.3)），防止误操作
4. **关闭方式**：
  - 点击面板内「✕」关闭按钮
  - 点击半透明遮罩区域
  - 再次点击「📂 历史」按钮
  - 按 Esc 键
5. **面板宽度**：固定 320px
6. **主界面状态**：保持原样，**不发生任何变形或重新布局**

## 会话列表设计

### 会话条目（折叠态）

```
▸ 📁 2026-04-02 20:15:30  |  TB321FU SM8750P  |  3 traces  |  125.3 MB
     └─ [会话时间]              [设备型号+SoC]     [文件数]     [总大小]
```

### 会话条目（展开态）

```
▾ 📁 2026-04-02 20:15:30  |  TB321FU SM8750P  |  3 traces  |  125.3 MB
   [📂 打开目录] [🗑 删除会话]
   ├─ trace_TB321FU_SM8750P_20260402_201530_001.perfetto-trace  42.1 MB
   │  [📂 目录] [📊 分析] [🗑 删除]
   ├─ trace_TB321FU_SM8750P_20260402_201530_002.perfetto-trace  46.6 MB
   │  [📂 目录] [📊 分析] [🗑 删除]
   └─ trace_TB321FU_SM8750P_20260402_201530_003.perfetto-trace  36.6 MB
      [📂 目录] [📊 分析] [🗑 删除]
```

### 操作按钮说明

| 按钮 | 作用域 | 功能 |
|-----|-------|------|
| 📂 打开目录 | 会话 | 打开会话所在文件夹 |
| 📂 目录 | trace | 打开文件所在目录并选中该文件 |
| 📊 分析 | trace | 联动 perfetto_analysis 模块分析该 trace |
| 🗑 删除 | 会话/trace | 删除会话目录或单个文件（弹窗确认） |

**说明**：trace 文件不支持双击打开（.perfetto-trace 无系统关联程序，Perfetto UI 也不支持直接 URL 打开本地文件），用户可通过「目录」按钮打开后拖拽到 Perfetto UI。

## 交互流程

### 打开历史记录

```
用户点击「📂 历史」按钮
    ↓
[首次加载] 扫描 output/trace/ 目录，解析会话信息，写入 SQLite 索引
    ↓
[后续加载] 从 SQLite 读取索引，仅增量扫描新目录
    ↓
按时间倒序渲染会话列表（QTreeWidget / QListWidget）
    ↓
显示磁盘占用统计（总大小、会话数）
```

### 分析 trace

```
用户选中某个 trace → 点击「📊 分析」
    ↓
[检查 perfetto_analysis 模块是否可用]
    ├── 不可用 → 提示「请安装 perfetto_analysis 模块」
    └── 可用 → 继续
    ↓
[切换到 perfetto_analysis Tab]
    ↓
[自动填入 trace 路径]
    ↓
[可选] 自动触发分析
```

### 删除会话

```
用户点击「🗑 删除」
    ↓
[弹出确认对话框] 「确定删除该会话及其中的 N 个 trace 文件？」
    ↓
[确认] → 删除目录 → 更新 SQLite 索引 → 刷新列表
[取消] → 无操作
```

## 与 Analysis 模块集成

### 联动方式

1. **EventBus 通信**：
  - 发布事件：`perfetto_capture.open_trace_for_analysis`
  - 载荷：`{"trace_path": "/path/to/trace.perfetto-trace"}`
2. **接收方（perfetto_analysis）**：
  - 监听事件后切换到 analysis Tab
  - 自动填入 trace 路径到输入框
  - 可配置是否自动开始分析

### 界面反馈

点击「📊 分析」后：

1. 按钮短暂变为加载状态
2. 左侧导航面板高亮 perfetto_analysis Tab
3. analysis Tab 自动滚动到 trace 输入区域
