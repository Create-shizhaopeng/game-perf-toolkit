## 设计概览

Perfetto 抓取 Tab 嵌入主窗口 `QStackedWidget`，通过左侧导航面板切换。页面需要展示：
1. 抓取配置面板（duration、buffer、导入、categories、ftrace 等）
2. 会话状态与控制按钮（固定在底部，始终可见）
3. 操作日志（固定在底部，与按钮同区）

**布局原则**：配置与长列表（Categories / Ftrace）位于 **QScrollArea** 内；**状态 + 按钮 + 日志** 位于滚动区域**之外**的底部，避免长列表将操作区挤出视口。

**特点**：
- **单栏全宽**：不再使用左右 `QSplitter` 分栏
- **上**：配置 + Categories +（可选）Ftrace — 内容增高时出现纵向滚动条
- **下**：状态行、操作按钮行、日志 — **固定高度区域**，不随上方滚动

## 公共组件

### 操作按钮

- 「开始」: 主色调按钮（绿色），抓取中变灰禁用
- 「保存」: 次要按钮，仅在抓取中可用（断线等待时禁用）
- 「停止」: 危险色按钮（红色），仅在抓取中可用（断线等待时禁用）
- 「放弃会话」: 断线等待等场景下可用，调用放弃逻辑无导出
- 按钮状态随抓取状态与设备连接状态自动切换

### 配置编辑

- Duration: QSpinBox（1~3600 秒）
- Buffer: QSpinBox（1~1000000 KB），可与自动计算联动
- 导入配置: QPushButton，点击弹出 `QFileDialog` 文件选择对话框（默认目录 `data/`，筛选 `*.json`），选择后自动加载配置刷新全部 GUI 控件
- Target Mode: QComboBox（全局/按包名）
- Packages: QLineEdit（仅 mode=packages 时可见）
- Categories: FlowWidget + QCheckBox（常用预设 + 自定义）
- Ftrace Events: FlowWidget + QCheckBox，默认隐藏，**可选事件从配置文件 `advanced.available_ftrace_events` 读取**（非硬编码），导入配置后动态重建

### 操作日志

- QTextEdit 只读模式
- 每行带时间戳前缀 `[HH:MM:SS]`
- 成功绿色 ✓，失败红色 ✗，警告黄色 ⚠
- 自动滚动到最新行

### 会话状态

- 状态指示器: 🟢 就绪 / ⏺ 抓取中 / 🟡 等待重连 / 🔴 设备断开
- 已保存段数: 数字显示
- 当前抓取时长: 计时器 MM:SS
- 设备信息: model + serial

## 交互流程

### 抓取流程

```
用户检查/编辑配置 → 点击「开始」
    ↓
[检查设备连接]
    ├── 未连接 → 提示连接设备
    └── 已连接 → 继续（引擎可先做陈旧 perfetto 会话清理）
    ↓
[在子线程中启动 perfetto]（Snapshot 或 Autobuffer 模式由能力探测决定）
    ├── 启动成功 → 状态变为「抓取中」，计时开始
    └── 启动失败 → 日志显示错误，状态恢复「就绪」
    ↓
用户可随时点击「保存」（视模式：clone 无中断 或 stop→record→restart）
    ↓
已保存段数 +1，日志更新
    ↓
用户点击「停止」
    ↓
[子线程: 停止并导出]
    ↓
有导出文件时自动打开导出目录；日志显示结果；状态恢复「就绪」
EventBus 发布 trace_ready 事件
```

### 断线处理

```
抓取中 USB 断开或设备列表为空
    ↓
[GUI: on_devices_changed([]) 或 捕获 DeviceUnavailableError]
    ↓
状态变为「🟡 等待重连」；禁用保存、停止；显示「❌ 放弃会话」
    ↓
[DeviceMonitor 约 2s 轮询]
    ├── 设备恢复 → worker reconnect 在设备上重启 perfetto，继续会话
    └── 用户点击「放弃会话」→ session_abandon()，无导出清理状态
              ↓
         若无设备：显示「🔴 设备断开」（非就绪）
```
