## 设计概览

Jank 自动检测功能需要在现有 Perfetto 抓取界面基础上扩展，核心设计原则：

1. **渐进披露**：仅勾选「启用 Jank 检测」后才显示监控配置面板
2. **实时反馈**：帧率曲线和统计信息实时更新
3. **视觉一致**：与现有 Atrace/Ftrace 配置区域风格统一
4. **状态清晰**：监控状态、抓取进度、应用状态一目了然

## Jank 监控面板

勾选「启用 Jank 检测」后，在 Atrace/Ftrace 区域**下方**显示 Jank 监控面板。面板采用**左右分栏布局**：左侧紧凑配置（固定 180px），右侧 FPS 曲线占据剩余空间。

### 面板展开顺序

```
☑ 启用 Ftrace 自定义   ☑ 启用 Jank 检测
           ↓                    ↓
  ┌────────────────┐
  │  Ftrace 配置区  │
  └────────────────┘
  ┌───────────────────────────────────────────────────────────────┐
  │  📊 Jank 监控                                                  │
  │  ┌───────────┬───────────────────────────────────────────┐   │
  │  │ 左侧配置   │  右侧 FPS 曲线 + 选区 + 统计            │   │
  │  │ (180px)   │  (剩余宽度)                                │   │
  │  └───────────┴───────────────────────────────────────────┘   │
  └───────────────────────────────────────────────────────────────┘
```

### 面板布局

```
┌──────────────────────────────────────────────────────────────────────┐
│  📊 Jank 监控                                                         │
│ ┌──────────────┬─────────────────────────────────────────────────┐  │
```

### 应用选择器设计

1. **下拉框内容**：包名格式，前台应用前缀 `★`
   - 例：`★ com.tencent.tmgp.cod`
2. **数据来源**：`adb shell pm list packages -3` + `adb shell dumpsys activity`
3. **刷新按钮**：点击重新获取当前运行的应用列表
4. **空状态**：无设备时显示 `请连接设备...`，无应用时显示 `无运行中的应用`
5. **不阻塞抓取**：未选择应用时 Perfetto 抓取仍可正常启动，仅跳过 Jank 监控

### 输入框约束

| 字段 | 类型 | 范围 | 默认值 |
|------|------|------|--------|
| 丢帧阈值 | QSpinBox | 1-30 | 动态（刷新率 × 5%） |
| 最大抓取 | QSpinBox | 1-10 | 3 |

## 实时帧率图表

图表位于 Jank 监控面板的**右侧区域**，与左侧配置面板并列。采用**深色背景**，与应用主题风格一致（参考 PerfDog 深色主题）。

### 图表视觉风格

| 属性 | 值 | 说明 |
|------|-----|------|
| 背景色 | `#1e1e2e` | Catppuccin Mocha base |
| 坐标轴色 | `#6c7086` | Overlay0，低对比度 |
| FPS 曲线 | `#cba6f7` (紫) | 2px 宽度 |
| Jank 标记 | `#FABF42` (黄) | 7px 圆点 |
| BigJank 标记 | `#F85149` (红) | 9px 圆点 |
| 网格 | **无** | 去掉背景网格，保持简洁 |

### 图表组件

| 组件 | 技术 | 说明 |
|------|------|------|
| 曲线图 | pyqtgraph.PlotWidget | 深色背景，200ms 刷新 |
| 时间轴 | X 轴 | 滚动窗口，默认 60 秒；支持鼠标滚轮缩放 |
| FPS 轴 | Y 轴 | 范围 0-150 |
| Jank 标记 | ScatterPlotItem | 黄色圆点 7px |
| BigJank 标记 | ScatterPlotItem | 红色圆点 9px |

### 横轴缩放

- **缩放方式**：鼠标滚轮
- **缩放范围**：10 秒 ~ 120 秒
- **默认显示**：最近 60 秒
- **缩放后行为**：曲线保持实时滚动，时间刻度自动调整

### 统计区域

位于图表下方的紧凑单行，包含统计和操作按钮：

```
FPS:58.3 Jank:5 BigJank:1 抓取:1/3 时长:02:30    ━FPS ●Jank ●BigJank ■抓取 ■暂停  [⏸暂停判定] [📊导出]
```

| 指标 | 计算方式 | 颜色 |
|------|---------|------|
| FPS | 监控期间所有帧的平均值 | 默认文字色 |
| Jank | 监控期间 Jank 事件总数 | 黄色 (#FABF42) |
| BigJank | 监控期间 BigJank 事件总数 | 红色 (#F85149) |
| 抓取 | 当前/最大 | 默认文字色 |
| 时长 | MM:SS | 默认文字色 |

### 特殊状态显示

**应用切到后台时**：
- 曲线显示 0 FPS
- 底部选区条显示深灰（非抓取选区 `#45475a`）
- 统计继续累计，但不计入后台期间的帧数据
- 恢复前台后等待 5 秒自动开始新的抓取选区

## 暂停判定按钮

### 按钮位置

位于图表下方统计行的右侧，与图例、导出按钮在同一行。紧凑小按钮（85px × 22px）。

### 按钮状态

|------|---------|------|

1. 按钮切换为「▶ 恢复判定」

3. 标题栏可选显示「⏸ 判定已暂停」
4. 帧率曲线继续绘制（只是不触发 Jank 保存）

### 状态栏设计

```
┌─────────────────────────────────────────────────────────────────┐
│  📊 状态: 🟢 监控中 (已抓取 1/3)                                 │
│         │   └─ 当前抓取进度                                      │

```

### 状态枚举

| 状态 | 图标 | 文案 | 说明 |
|------|------|------|------|
| 就绪 | 🟢 | 就绪 | 配置完成，可开始 |
| 监控中 | 🟢 | 监控中 (已抓取 N/M) | 正在监控帧率 |
| 等待触发 | 🟡 | 检测到 Jank，等待稳定... | 触发后的稳定期 |
| 保存中 | 🟡 | 正在保存 trace... | 自动保存 trace |
| 已暂停 | ⏸️ | 已暂停（应用后台） | 应用切到后台 |
| 已完成 | ✅ | 完成 (共抓取 3 个 trace) | 达到最大次数 |
| 错误 | ❌ | 错误: 应用进程已退出 | 应用被杀或设备断开 |

### 按钮区布局

```
[▶ 开始] [⏹ 保存] [■ 停止] [📤 导出] [📂 历史]
```

Jank 检测启用时，按钮行为调整：

| 按钮 | 正常模式 | Jank 模式 |
|------|---------|----------|
| ▶ 开始 | 开始 Perfetto 抓取 | 开始抓取 + 帧率监控 |
| ⏹ 保存 | 手动保存当前段 | 同上（仍可手动保存） |
| ■ 停止 | 停止抓取 | 停止监控 + 自动保存未保存的 trace |
| 📤 导出 | N/A | 导出帧率数据（监控停止后启用） |

## 配置锁定状态

监控期间，部分配置需要锁定以防止用户修改导致问题。

### 锁定规则

| 配置项 | 监控期间 | 说明 |
|--------|---------|------|
| Duration | 🔒 锁定 | Perfetto 已启动 |
| Buffer | 🔒 锁定 | Perfetto 已启动 |
| Atrace Categories | 🔒 锁定 | Perfetto 已启动 |
| Ftrace 配置 | 🔒 锁定 | Perfetto 已启动 |
| 目标应用 | 🔒 锁定 | 监控中不可切换应用 |
| **丢帧阈值** | 🔓 可改 | 实时生效 |
| **最大抓取次数** | 🔓 可改 | 实时生效 |

### 锁定视觉表现

```
┌─────────────────────────────────────────────────────────────────┐
│  ⚙ 抓取配置                                        🔒 监控中    │
├─────────────────────────────────────────────────────────────────┤
│  Duration    Buffer                                             │
│  [  30  ] 秒 [auto] MB   ← 输入框灰色禁用态                      │
│                                                                  │
│  ☑ 启用 Ftrace 自定义 ← 复选框灰色禁用    ☑ 启用 Jank 检测      │
└─────────────────────────────────────────────────────────────────┘
```

- 锁定项：输入框/复选框变为 disabled 状态（灰色）
- 标题栏右侧显示「🔒 监控中」提示
- 可修改项：保持正常交互状态

## 交互流程

### 启动 Jank 监控

```
1. 用户勾选「启用 Jank 检测」
   ↓
2. 显示 Jank 监控配置面板
   ↓
3. 用户选择目标应用
   ↓
4. 用户（可选）调整丢帧阈值和最大抓取次数
   ↓
5. 用户点击「▶ 开始」
   ↓
6. 锁定 Perfetto 配置项
   ↓
7. 启动 Perfetto 抓取 + 帧率监控
   ↓
8. 显示实时帧率图表区域
   ↓
9. 状态更新为「🟢 监控中 (已抓取 0/3)」
```

### Jank 触发保存

```
1. 帧率监控检测到 1 秒内 Jank 数 > 阈值
   ↓
2. 状态更新为「🟡 检测到 Jank，等待稳定...」
   ↓
3. 等待 2 秒稳定期
   ├── 持续卡顿 → 继续延后（最多 8 秒）
   └── 稳定 → 继续
   ↓
4. 状态更新为「🟡 正在保存 trace...」
   ↓
5. 自动保存当前 trace 段
   ↓
6. 日志显示「检测到 Jank，已自动保存 trace」
   ↓
7. 状态更新为「🟢 监控中 (已抓取 N/M)」
   ↓
8. 继续监控（或达到最大次数后停止）
```

### 应用切到后台

```
1. 帧率监控检测到目标应用不在前台
   ↓
2. 状态更新为「⏸️ 已暂停（应用后台）」
   ↓
3. 曲线显示 0 FPS，暂停抓取判定
   ↓
4. 选区条当前区域变为灰色（非抓取选区）
   ↓
5. [等待应用恢复]
   ├── 应用恢复前台 → 等待 5 秒 → 自动恢复抓取判定 → 新建抓取选区
   └── 应用进程被杀 → 自动保存 trace 并停止
```

### 暂停判定

```
1. 用户点击「⏸ 暂停判定」
   ↓
2. 结束当前抓取选区，开始非抓取选区
   ↓
3. 按钮变为「▶ 恢复判定」
   ↓
4. 曲线继续绘制，但 Jank 不触发保存
   ↓
5. 选区条当前区域变为灰色
   ↓
6. [用户点击「▶ 恢复判定」]
   ↓
7. 结束非抓取选区，新建抓取选区
   ↓
8. 按钮恢复为「⏸ 暂停判定」
```

### 手动停止

```
1. 用户点击「■ 停止」
   ↓
2. [检查是否有未保存的 trace]
   ├── 有 → 自动保存当前段 → 继续
   └── 无 → 继续
   ↓
3. 停止 Perfetto 抓取
   ↓
4. 停止帧率监控
   ↓
5. 解锁所有配置项
   ↓
6. 状态更新为「🟢 就绪」
   ↓
7. 日志显示「已自动保存并导出 N 段 trace」
```
