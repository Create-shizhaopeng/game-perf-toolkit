## 适用场景

当用户请求分析 Perfetto trace 但未明确指定分析场景时使用本 SOP。

## 场景分类流程

1. 调用 `pa_trace_overview` 获取 trace 元数据
2. 根据元数据判断 trace 可能包含的场景：
   - 帧数 > 0 且有 jank_records → 卡顿分析场景
   - 进程列表中包含系统进程 → 可能涉及 ANR 或系统级问题
   - trace 时长 > 30s → 可能包含多个场景阶段
3. 结合用户意图选择对应场景 SOP

## 时间范围确定策略

1. **用户已指定**: 直接使用用户给出的时间范围
2. **Agent 自动确定**: 通过 `pa_trace_overview` 的 scenario_phases 字段识别场景阶段，选择相关阶段的时间范围
3. **无法确定时 MUST 向用户询问**: 当 trace 包含多个不相关场景且用户意图不明确时，列出可能的场景阶段及其时间范围，请用户选择

## 场景 SOP 路由

| 用户意图关键词 | 对应 SOP |
|---------------|---------|
| 卡顿、丢帧、帧率、掉帧 | jank-analysis.md |
| ANR、无响应 | anr-analysis.md |
| 内存、泄漏、OOM | memory-analysis.md |
| 其他 / 不确定 | 使用本 SOP 的兜底分析流程 |

## 兜底分析流程

当无法匹配具体场景 SOP 时：

1. 调用 `pa_trace_overview` 了解 trace 概况
2. 根据用户意图选择相关的分析工具组合
3. 调用 `pa_detect_jank` 检查是否有卡顿
4. 对最可能相关的 2-3 个维度调用 `pa_analyze_dimension`
5. 调用 `pa_compress_results` 生成摘要
6. 基于摘要向用户报告发现，建议下一步分析方向
