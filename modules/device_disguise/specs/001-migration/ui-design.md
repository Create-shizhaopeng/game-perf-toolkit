## 设计概览

设备伪装 Tab 嵌入主窗口的 `QStackedWidget` 中，通过左侧导航面板切换。页面内需要展示：
1. 设备当前状态（连接/伪装状态）
2. 伪装/还原操作区（品牌/厂商/型号输入 + 操作按钮）
3. 档案快捷选取（联想输入 + 档案列表）
4. 操作日志（伪装/还原进度）

## 公共组件

### 输入框（带联想）

- 使用 `QComboBox`（editable）+ `QCompleter`
- 联想来源：设备档案库中对应字段的所有值
- 选中联想项时联动填充其他两个字段

### 操作按钮

- 「伪装」：主色调按钮（紫色/蓝色），伪装执行中变为灰色禁用
- 「还原」：次要按钮，设备未伪装时灰色禁用
- 「选择档案」：弹出档案列表弹窗
- 「保存档案」：弹出保存对话框

### 操作日志

- `QTextEdit` 只读模式
- 每行带时间戳前缀
- 成功步骤绿色 ✓，失败步骤红色 ✗
- 自动滚动到最新行

### 保存对话框

- 无框对话框（匹配主框架风格）
- 显示 brand/manufacturer/model + notes 输入框
- 确认/取消按钮

### 档案选取弹窗

- 无框弹窗，列出所有档案
- 支持搜索过滤
- 双击或回车选中后关闭并填充

## 交互流程

### 伪装流程

```
用户输入目标信息 → 点击「伪装」
    ↓
[检查目标组合是否在档案库中]
    ├── 不在 → 弹出保存对话框
    │          ├── 保存 → 保存档案后继续
    │          └── 跳过 → 直接继续
    └── 已在 → 直接继续
    ↓
[在子线程中执行服务层 disguise()]
    ↓
进度回调 → 更新日志区
    ↓
完成/失败 → 更新设备状态显示
```

### 还原流程

```
用户点击「还原」
    ↓
[检查设备是否处于伪装状态]
    ├── 未伪装 → 提示无需还原
    └── 已伪装 → 在子线程中执行 reset()
    ↓
进度回调 → 更新日志区
    ↓
完成/失败 → 更新设备状态显示
```
