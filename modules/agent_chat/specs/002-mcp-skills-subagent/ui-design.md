## 设置面板扩展

在现有设置弹窗的三个 Tab 基础上，新增 Tab 4（MCP 管理）和 Tab 5（Skills 管理）。

### Tab 4: MCP 管理

```
┌── MCP 服务器管理 ─────────────────────────────────────┐
│                                                        │
│  ┌──────────────────────────────────────────────────┐  │
│  │ 服务器名         │ 传输  │ 状态     │ 工具数 │ 操作│  │
│  │──────────────────│───────│──────────│────────│─────│  │
│  │ perfetto-mcp     │ stdio │ 🟢 已连接 │  12   │ [⟳] │  │
│  │ custom-server    │ sse   │ 🔴 断开   │  --   │ [⟳] │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  选中服务器的可用工具:                                    │
│  ┌──────────────────────────────────────────────────┐  │
│  │ • perfetto_query — 执行 SQL 查询                  │  │
│  │ • perfetto_open_trace — 打开 trace 文件           │  │
│  │ • perfetto_find_slices — 搜索 slice              │  │
│  │ ... (共 12 个)                                    │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  [➕ 添加服务器]   [📝 编辑配置文件]                      │
│                                                        │
│  SDK 版本: mcp v1.26.0  ⚠️ v1.28.0 可用                │
│                                                        │
└────────────────────────────────────────────────────────┘
```

**交互说明**：
- 点击服务器行：下方显示该服务器的可用工具列表
- 🟢/🔴/🟡 状态指示灯：已连接/断开/连接中
- `[⟳]` 重连按钮：手动触发重新连接
- `[➕ 添加服务器]`：弹出表单填写 name/command/args/transport
- `[📝 编辑配置文件]`：用系统编辑器打开 `mcp_servers.json`
- SDK 版本提示：当检测到新稳定版时显示

│                                                        │

│  │ perfetto-analysis  │ perfetto_analysis │  SOP:9    │  │

│  │  ├ sop/jank-analysis.md                          │  │
│  │  ├ sop/startup-analysis.md                       │  │
│  │  ├ sop/general-analysis.md                       │  │
│  │  └ ... (共 9 个 SOP + 1 个 patterns + 1 个 SQL)   │  │
│  └──────────────────────────────────────────────────┘  │
│                                                        │
│  搜索路径:                                              │
│  • modules/*/skills/*/SKILL.md (默认)                  │

**交互说明**：
- 点击 Skill 行：下方显示详细信息和子资源列表
- 双击子资源：用系统编辑器打开对应文件
- `[➕ 添加搜索路径]`：弹出目录选择器添加 Skill 搜索路径
- `[🔄 刷新]`：重新扫描搜索路径
- Skill 列表只读——Skill 由模块管理，不支持在 GUI 中增删

## 左侧面板变更

将原"SOP 管理"区域替换为**知识管理**面板，仅展示 Skill 信息。SOP 已全部移除，不再有独立的 SOP 列表。

```
┌── 知识管理 ─────────────────────┐
│                                 │
│ 📚 已加载 Skills (2)             │
│  ├ 🧠 perfetto-analysis        │  ← 自动发现
│  │   SOP:9 | 模式:1 | SQL:1     │
│  └ 🧠 skill-creator            │
│     子资源: —                    │
│                                 │
│ [🔄 刷新]  [⚙ 搜索路径设置]      │
│                                 │
└─────────────────────────────────┘
```

**交互说明**：
- Skills 条目只读，点击展开显示描述和子资源列表
- 双击子资源：用系统编辑器打开对应文件
- `[🔄 刷新]`：重新扫描搜索路径发现 Skill
- `[⚙ 搜索路径设置]`：跳转到 Tab 5 的搜索路径配置

## 消息区域扩展

### Sub-agent 任务卡片

当主 Agent 创建子 Agent 时，显示任务进度卡片：

```
  ┌─ 🤖 子 Agent 任务 ──────────────────────────────────┐
  │ 📋 分析 trace: TB522FU_SM8750P_20260401.trace       │
  │ 🧠 Skill: perfetto-analysis                         │
  │ 🔧 Provider: GLM-4-Plus                             │
  ├──────────────────────────────────────────────────────┤
  │ ⏳ 分析中... (已用时 15.2s)                           │
  └──────────────────────────────────────────────────────┘
```

**完成后**：

```
  ┌─ 🤖 子 Agent 任务 ──────────── ✅ 完成 (23.5s) ─────┐
  │ 📋 分析 trace: TB522FU_SM8750P_20260401.trace       │
  │ 🧠 Skill: perfetto-analysis                         │
  ├──────────────────────────────────────────────────────┤
  │ 检测到 5 个卡顿帧，主要原因:                          │
  │  1. 主线程 Binder 阻塞 (3 帧)                       │
  │  2. RenderThread 超时 (2 帧)                         │
  │ ▶ 展开完整摘要                                       │
  └──────────────────────────────────────────────────────┘
```

**失败+重试**：

```
  ┌─ 🤖 子 Agent 任务 ──────────── ❌ 失败 ──────────────┐
  │ 📋 分析 trace: TB522FU_SM8750P_20260401.trace       │
  ├──────────────────────────────────────────────────────┤
  │ 错误: LLM 调用超时                                   │
  │ 已自动重试 1 次，仍然失败。                           │
  │ [🔄 再次重试]   [⏭ 跳过]                             │
  └──────────────────────────────────────────────────────┘
```

### MCP 工具调用标识

MCP 工具调用卡片与本地工具卡片视觉区分：

```
  ┌─ 🌐 perfetto_query (MCP) ─────── ✅ 完成 (2.1s) ───┐
  │ sql: SELECT * FROM slice WHERE name LIKE '%egl%'    │
  ├──────────────────────────────────────────────────────┤
  │ 返回 42 行数据                                       │
  │ ▶ 展开结果                                           │
  └──────────────────────────────────────────────────────┘
```

- MCP 工具使用 🌐 前缀和 `(MCP)` 标签
- 本地工具继续使用 📎 前缀
- 降级到本地工具时显示 `(降级)` 标签

## 欢迎页更新

更新快捷入口和状态指示。快捷入口按钮的文案由已加载的 Skill 描述动态生成，不再硬编码 SOP 名称。

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│            🤖 Agent 智能助手                          │
│                                                      │
│     描述你的任务，我将自动匹配 Skill 完成分析。        │
│                                                      │
│  ┌────────────────────────────────────────────────┐  │
│  │  [🔍 Trace 分析]    [📊 PerfDog 分析]          │  │
│  │  [⚙ 策略审查]      [🔬 综合分析]              │  │
│  │  [📚 导入分析文档]                              │  │
│  └────────────────────────────────────────────────┘  │
│                                                      │
│  🧠 Skills: perfetto-analysis, knowledge-curator,   │
│     skill-creator                                    │
│  🌐 MCP: perfetto-mcp (🟢 已连接, 12 工具)          │
│                                                      │
└──────────────────────────────────────────────────────┘
```

**说明**：
- 快捷入口按钮点击后直接发送预设的用户消息（如"帮我分析这个 trace 的性能问题"），Agent 自动匹配 Skill 进行分析
- `[📚 导入分析文档]` 按钮触发文件选择器，选中文件后发送"请帮我将这份文档提炼为 Skill 知识"，激活 `knowledge-curator` Skill
