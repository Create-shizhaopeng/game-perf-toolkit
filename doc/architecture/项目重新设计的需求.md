# 重构背景
项目最开始只是简单的小工具编写，架构设计，多人通过多个speckit+ai开发协作的场景未考虑。
界面的实现，编译规范，版本要求，项目架构，技术选型等等没有做大项目的规划


# 重构需求
多人共同通过speckit开发完成一个大项目，每个人的speckit需要遵循统一的基本规则
本项目需要支持用户通过界面交互，可以通过命令行交互（Agent可以通过命令行的形式获取想要的数据）
本工具各个不同的模块独立开发，最终整体编译成一个工具
子模块中spec等技术文档的，源代码，素材等目录需要合理规划
考虑项目之后的扩充与维护
需要对当前模块的各种文档资源，源码进行重新规划
通过对话了解当前想要做的需求帮助我做一个合理的项目架构设计。项目架构设计的这部分不需要纳入git管理。并且我们对话结束后给我一些架构学习的路线与材料。
